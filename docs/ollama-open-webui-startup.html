Start Ollama and Open WebUI automatically

You've got Ollama and Open WebUI working, and now you want your own private ChatGPT ready every time you turn on the PC. Most guides assume Docker. Here's how to do it without Docker on Windows, Mac and Linux, plus the mistakes that make it "randomly" stop working. Current as of October 2026.

Part 1: Ollama usually starts itself

The Ollama installer for Windows and Mac already starts Ollama when you log in. It sits in the tray or menu bar and serves models at http://127.0.0.1:11434. To check, restart and open that address in a browser. It should say "Ollama is running".

On Linux, the install script sets Ollama up as a system service. systemctl status ollama shows whether it's on, and sudo systemctl enable --now ollama turns it on at boot.

So the part you actually have to solve is Open WebUI.

Part 2: Start Open WebUI at login

If you installed Open WebUI with pip (it needs Python 3.11), it starts with open-webui serve. Put it in a virtual environment so other Python projects can't break it:

python -m venv C:\ai\open-webui\.venv
C:\ai\open-webui\.venv\Scripts\pip install open-webui

Windows

Save this as open-webui.bat:

@echo off
:loop
C:\ai\open-webui\.venv\Scripts\open-webui serve --port 8080
timeout /t 10 /nobreak >nul
goto loop

Press Win + R, type shell:startup, and put a shortcut to the .bat file in the folder that opens. It now starts every time you log in, and the loop restarts it if it crashes. Open http://localhost:8080 once it's up. The first start takes a minute or two.

Mac

Create a Launch Agent at ~/Library/LaunchAgents/com.openwebui.plist that runs ~/ai/open-webui/.venv/bin/open-webui serve --port 8080 with RunAtLoad and KeepAlive set to true. Then load it with launchctl load ~/Library/LaunchAgents/com.openwebui.plist.

Linux

A user service is the cleanest way. Save this as ~/.config/systemd/user/open-webui.service:

[Unit]
Description=Open WebUI

[Service]
ExecStart=%h/ai/open-webui/.venv/bin/open-webui serve --port 8080
Restart=on-failure

[Install]
WantedBy=default.target

Then run systemctl --user enable --now open-webui.
