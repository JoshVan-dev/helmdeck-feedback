Starter build

Get a phone alert when a web page changes, free

Waiting for a restock, a price drop, a new job post or a school announcement? Helmdeck's Web page watcher checks the page for you and tells you what changed in one plain sentence, so you stop refreshing it.

What it does

  • Checks a page on a timer. Every 30 minutes by default. It compares the page's readable text, so changes to its scripts and styling don't count.
  • Says what changed. When the text changes, your AI writes a one-line summary, like "Two new jobs were added: Junior Designer and QA Tester." It uses the AI keys or local model you've set up in Helmdeck, and if you have none it just says the page changed.
  • Or waits for one word. Set lookFor to a word like "In stock" or "2027 dates" and it only tells you when that word appears.
  • Pings your phone. The tile flags "needs you" when there's news, and with phone alerts on you get a notification through ntfy or Discord.

Set it up in a few minutes

  1. Install Helmdeck on Windows, Mac or Linux.
  2. Open Browse, pick Web page watcher and press Make it.
  3. Open the build's config.json: 
    {
  "url": "https://example.com/careers",
  "everyMinutes": 30,
  "lookFor": ""
}
  4. Start it, and turn on phone alerts to get the ping. To watch more pages, make another copy of the build for each one.

Good to know

  • It reads the page the simple way. It fetches the page's HTML, like a quick visit with no browser. Pages that only fill in their content with JavaScript, or that need you to log in, may look empty or unchanged to it.
  • Be kind to the site. Checking every 30 minutes is plenty for most pages. Some sites don't allow automated checks, so read their terms first.
  • It needs your PC on. It runs on your computer. Turn on "Restart if it stops" and "Start with Windows" so it keeps going after a reboot.

How it compares

Browser extensions like Distill and hosted services like Visualping are good, and hosted services keep checking when your PC is off. The watcher is different in three ways: there's no monthly page limit, the AI summary uses your own keys or a free local model, and it sits on the same screen as everything else you run in Helmdeck.
