How they use AI

Builds use the AI keys saved in Helmdeck, so you never paste a key into code. Helmdeck tries a local model first if you have one (Ollama or LM Studio), then free tiers, then paid keys.

Make your own

Any folder with a script can be a Helmdeck build. Add two lines and it reports live status to its tile:

const { report } = require('./helmdeck-status');
report('running', { stat: '42 new leads', message: 'Checked 2 min ago' });

When it's good, press Share and it shows up in everyone's Browse.
