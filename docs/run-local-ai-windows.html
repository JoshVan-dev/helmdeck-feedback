Run Ollama, ComfyUI and your own AI bots on Windows

Local AI on Windows usually means one terminal per tool and a lot of guessing about what's still running. Here's a setup that keeps it simple, current as of October 2026.

1. Pick what your PC can run

The graphics card's memory (VRAM) decides most of it. In Windows, open Task Manager, go to Performance, then GPU, and look at "Dedicated GPU memory".

Check each model's license before selling what you make with it. Some are free for personal use only.

2. Chat models: Ollama or LM Studio

Ollama is the simplest. Install it from ollama.com, then in PowerShell:

ollama pull gemma4
ollama run gemma4

Each model comes in several sizes. Pick the one that fits your VRAM on its page at ollama.com/library.

LM Studio gives you the same models with a point-and-click app. Both run a local server that other apps can use, at localhost:11434 for Ollama and localhost:1234 for LM Studio.

3. Images and video: ComfyUI

ComfyUI runs nearly every open image and video model. The easiest route on Windows is the ComfyUI desktop app. Download a model into its models folder, then load a template workflow for it.

4. Your own bots and scripts

Most AI builds are a folder with a Python or Node script. Write down the command that starts each one, and the folder it runs in.

5. Put it all on one screen

This is the part Helmdeck does. On first run, Quick setup finds Ollama, LM Studio and ComfyUI and adds them in one click. Drag in your bot folders and each becomes a tile you double-click to start. Turn on "Restart if it stops" for anything that has to stay up, and phone alerts if you want a ping when one needs you.

Your AI keys live in Helmdeck too. Builds get them automatically, and Helmdeck uses local models first, then free tiers, then paid ones.

Troubleshooting

"Windows protected your PC"

New apps that aren't widely downloaded yet show this. Click "More info", then "Run anyway".

Out of memory errors in ComfyUI

Use a smaller version of the model (FP8 or GGUF), lower the resolution, or close other apps that use the GPU.

A model is slow

If it doesn't fit in VRAM it spills into normal memory and slows to a crawl. Pick a smaller model from the table above.
