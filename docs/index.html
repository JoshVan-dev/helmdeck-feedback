Questions

Before you download

What counts as a build?

Anything you can start with a command, a file or a link: a Python or Node script, a bot, a local web app, a game mod tool, or an AI app like ComfyUI or Open WebUI.

Does my build need changes to work?

No. Any build starts and stops from Helmdeck as it is. Adding the two-line status helper is optional and gives the tile live stats.

How do phone alerts work?

Install the free ntfy app and scan the code in Helmdeck, or paste a Discord webhook. Alerts only carry the build's name and its status line.

Windows says "Windows protected your PC". Is it safe?

Helmdeck is new, so Windows doesn't recognize the installer yet. Click "More info", then "Run anyway". Signed installers are on the way.

My Mac says Helmdeck "can't be opened". What do I do?

Helmdeck isn't signed with Apple yet, so macOS blocks it the first time. Open System Settings → Privacy & Security, scroll down and click "Open Anyway" next to Helmdeck. You only need to do this once. Newer Macs (M1 and later) use the Apple silicon download; older Intel Macs use the Intel one.

Which Linux download should I use?

On Ubuntu, Debian or Mint, use the .deb file and open it with your software installer. On any other distro, use the .AppImage: mark it as executable (right-click → Properties → Allow executing, or chmod +x) and double-click it.

Is lifetime really lifetime?

Yes. Pay once and every future update is included. The early-bird price goes up later.

How do I report a bug or ask for a feature?

Click the light bulb in Helmdeck, or open the ideas board. The most-voted ideas get built first.
