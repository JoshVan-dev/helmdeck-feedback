Questions

 

What counts as a "build"?

Anything you made or use: a Python or Node script, a bot, a local web app, a game mod tool, an AI app like ComfyUI or Open WebUI. If you can start it with a command, a file or a link, Helmdeck can run it.

Does Helmdeck see my code or my AI keys?

No. Everything stays on your PC. Your keys are stored encrypted on your machine, and builds you install from others never get your raw keys.

Windows says "Windows protected your PC". Is it safe?

Helmdeck is new, so Windows doesn't recognize it yet. Click "More info", then "Run anyway". Signed installers are coming.

How do I show live stats like profit?

Your build writes a small status.json file (or serves a status link). The free Python and Node helpers make it two lines of code.

Is lifetime really lifetime?

Yes. Pay once and every future update is included. The early-bird price goes up later.

How do I report a bug or suggest a feature?

Click the light bulb in Helmdeck, or open the ideas board. The most-voted ideas get built first.
