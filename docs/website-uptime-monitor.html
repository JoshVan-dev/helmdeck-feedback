Starter build

A free website uptime monitor that runs on your own PC

If you run a few websites, a shop or a side project, you want to know the moment one goes down. Hosted monitors cap you with free-plan limits, and self-hosted ones like Uptime Kuma want a server or Docker. Helmdeck's Uptime monitor starter build runs on the computer you already have.

What it does

  • Checks every site on a timer. Every 5 minutes by default, all your sites at once.
  • Catches more than "down". A site counts as a problem if it doesn't answer, answers with an error code, takes longer than 5 seconds, or is missing a bit of text you tell it to look for. That last one catches broken pages that still load.
  • Shows it on one tile. The tile reads "3 of 3 up" with each site's uptime percentage, and it charts the slowest response time so you can spot a site getting slower.
  • Pings your phone. With phone alerts on, the tile turning red sends you a notification through ntfy or Discord saying which site has the problem and why. The tile tells you when it's back up and how long it was down.

Set it up in a few minutes

  1. Install Helmdeck on Windows, Mac or Linux.
  2. Open Browse, pick Uptime monitor and press Make it.
  3. Open the build's config.json and list your sites: 
    {
  "sites": [
    { "name": "My shop", "url": "https://myshop.com" },
    { "name": "Blog", "url": "https://myblog.com" }
  ],
  "everyMinutes": 5,
  "slowSeconds": 5,
  "lookFor": ""
}
  4. Start it. Turn on phone alerts to get the ping, and turn on "Restart if it stops" and "Start with Windows" so it keeps watching after a reboot.

It's plain Node.js that runs with Helmdeck's built-in Node, so there's nothing else to install. You can open the code and change anything.

One honest limit: it checks from your computer, so it can't warn you while your PC is off or your internet is down. If a site earns you real money, use it alongside a hosted monitor rather than instead of one.

Common questions

Is it free?

The starter build is free, and Helmdeck Free holds 3 builds. Phone alerts, restart on crash and start with your PC come with Pro, which is $39 once.

Can it watch things that aren't websites?

This build checks web addresses, including local ones like http://localhost:3000. Helmdeck already watches the bots and scripts you run in it, and tells you when one crashes, so you don't need a separate check for those.
