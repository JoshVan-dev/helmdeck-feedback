How to install Helmdeck

Helmdeck is new and its installers aren't signed by Microsoft or Apple yet, so both show a warning the first time you open it. Here's what to click, why the warning appears, and how to check your download is the real one.

Windows

  1. Download Helmdeck-Setup.exe from the official downloads page.
  2. Open it. If a blue box says "Windows protected your PC", click More info, then Run anyway.
  3. Follow the installer: choose who it's for and where it goes (the defaults are fine), then click Install. It adds a Start menu entry and a desktop shortcut.

Prefer not to install anything? The portable .exe on the same page runs without installing.

Why does Windows warn me?

Windows SmartScreen warns about any app it hasn't seen many times before, and about installers that aren't signed with a paid code-signing certificate. Helmdeck is new and not signed yet, so you see the warning. It doesn't mean Windows found anything wrong. A signed installer is on the way.

Mac

  1. Download the .dmg: the Apple silicon one for M1 and newer, the Intel one for older Macs.
  2. Open it and drag Helmdeck into Applications.
  3. The first time, macOS says Helmdeck "can't be opened". Open System Settings → Privacy & Security, scroll down and click Open Anyway next to Helmdeck. You only do this once.

Linux

  • Ubuntu, Debian or Mint: download the .deb and open it with your software installer.
  • Any other distro: download the .AppImage, mark it as executable (right-click → Properties → Allow executing, or chmod +x), then double-click it.

Check your download is the real one

Only download Helmdeck from helmdeck.org or github.com/JoshVan-dev/helmdeck-releases. Copies on other sites aren't ours.

To be sure the file wasn't changed, compare its fingerprint (SHA-256) with the one GitHub shows next to each file on the downloads page.

Windows (PowerShell, in your Downloads folder):

Get-FileHash .\Helmdeck-Setup-*.exe -Algorithm SHA256

Mac or Linux (Terminal):

shasum -a 256 ~/Downloads/Helmdeck-*

If the long code matches the one on GitHub, it's the file we published.

Updates and uninstalling

The installed version downloads updates in the background and offers to restart into the new version. The portable .exe doesn't update itself, so grab the newest one from the downloads page now and then. To remove it on Windows, open Settings → Apps → Installed apps, find Helmdeck and choose Uninstall. Your builds stay in their own folders.
