Helmdeck vs PM2, NSSM and Task Scheduler

If you've got a Discord bot, trading bot or script that has to stay up on a Windows PC, these are the usual options. They all restart things. The difference is how much setup they take and whether you can see what's going on.

The short version

Pick PM2 if you live in a terminal, mostly run Node apps, and deploy to Linux servers too. It's free and very capable, but on Windows its built-in pm2 startup command doesn't work, so starting with your PC needs an extra tool.

Pick NSSM if the program has to run as a real Windows service, before anyone signs in, on a machine nobody looks at. It's free and solid, but it has no dashboard and its last stable release came out in 2014.

Pick Task Scheduler if you only need something to start at a set time and you don't mind clicking through its settings. It's built into Windows, but it isn't designed to watch a program and bring it back when it crashes.

Pick Helmdeck if you want your bots on one screen where you can see which are running, read their logs, restart them after a crash, start them with your PC and get a ping on your phone when one goes down. It works with Node, Python or any command, and you set it up with clicks.

Where each one gets awkward

PM2 on Windows

PM2 is a great process manager, but it was built for Linux. On Windows, pm2 startup doesn't set anything up, so people reach for add-ons like pm2-installer or a Windows service wrapper, and the older pm2-windows-service package is deprecated. You also manage everything with commands, which is fine at a desk and less fine when you just want to know if your bot is up.

NSSM

NSSM turns any program into a Windows service, so it can run before anyone signs in. That's exactly right for a headless server. For a bot on your own PC it means a service you set up from a command prompt, logs you have to point somewhere yourself, and no easy way to see what's happening.

Task Scheduler

Task Scheduler is good at "run this at 9am" and "run this when I sign in". Its restart setting only kicks in when a task fails to start, so a bot that runs for an hour and then crashes usually stays down.

How Helmdeck does it

Add your bot's folder or command and it becomes a tile. Use {node} bot.js to run a Node bot with Helmdeck's built-in Node, or any command like python bot.py. Turn on "Restart if it stops" and a crash is back in seconds, with a short wait between tries so a broken bot doesn't loop forever. Turn on start with your PC and Helmdeck opens quietly in the tray when you sign in and starts your bots. Closing the window keeps it running in the tray.

With phone alerts on, you get a ping when a bot crashes, finishes or needs you. Two lines of code from your bot can also put a live number on its tile, like today's P/L or members online.

One honest limit: Helmdeck runs when you're signed in to Windows. If your machine has to run a program with nobody signed in, NSSM or a Windows service is the better tool.
