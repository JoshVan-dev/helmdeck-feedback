# helmdeck-feedback
Ideas, bugs and the catalog for Helmdeck

- **Ideas and bugs:** posted from the light-bulb button in Helmdeck. Vote with 👍.
- **Crash reports:** issues titled `Crash: …`, sent only when a user agrees.
- **Live catalog:** `catalog/` is built every hour by the Helmdeck catalog
  action and published to the `catalog` branch. See catalog/README.md.
